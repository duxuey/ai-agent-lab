# temperature=0 能保证复现吗

**Q：** `temperature=0` 能保证两次调用结果完全一样吗？

**A：** 不能。它只是把采样变成"每次选概率最高的"，但底层还有浮点累加顺序、批处理组成、GPU 并行归约、后端模型版本在变。

## 现场验证（30 秒）

同一个 prompt 连跑 3 次，把输出对比一下：

```powershell
1..3 | ForEach-Object { .\.venv\Scripts\python.exe day0_smoke.py >> out.txt }
```

## 工程结论

要"稳定"应该做：结构化约束 + 输出校验 + 重试 + 记录模型版本，而不是把温度调到 0。

**一句话：** 温度只决定选哪个词，不决定世界是否静止。
