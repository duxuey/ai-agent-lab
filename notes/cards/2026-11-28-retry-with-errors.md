# 重试要把错误信息原样回灌

**Q：** 校验失败后重试，为什么不能简单地"再问一次"？

**A：** 因为模型不知道错在哪。必须把**具体的错误文本**（哪个字段、期望什么格式）
作为一条 user 消息发回去，它才能修正。

**实测：** 第一次失败回灌 `Field required`，模型补了字段但值填"未提及"；
第二次回灌 `String should match pattern '^(高|中|低)$'`，它才填对。

**这就是用 Pydantic 的理由：** 它的 `errors()` 里带着约束本身，天然是好的重试提示。
手写 `if not xxx: return "格式错误"` 给的信息量不够，模型只能瞎猜。

**成本意识：** 每次重试都是 3 倍 token/延迟，重试是保险，不是常态。

**一句话：** 不知道错在哪的重试，只是重复犯错。
