# Capstone：每日 AI 技术简报 Agent

> 每天自动抓取固定几个信息源，去重、按你关心的方向排序，写成 300 字中文简报，带原文链接。
> 你读完点「有用 / 没用」，反馈进入下一轮排序。

## 1. 用户与场景

- 用户：我自己（延伸用户：同样在学 AI Agent 的同行）
- 场景：每天早上 8:30，打开终端或邮箱，读一份 3 分钟能看完的简报
- 频率：每天 1 次

## 2. 现在的做法与痛点

- 现在：手工刷 Hacker News、arXiv cs.AI、GitHub Trending、3 个博客 RSS，约 40 分钟/天
- 痛点：
  1. 同一件事被 5 家媒体转载，重复阅读
  2. 排序靠编辑推荐，不是按「我在学 Agent」这个方向
  3. 刷完没留下记录，一周后想找某条找不到
- 成本：约 40 分钟/天 × 250 天 ≈ 166 小时/年

## 3. 基线实测（2026-11-19）

- 样本：`samples/news.txt`，10 条真实资讯（标题 + 摘要）
- 方式：deepseek-flash，temperature=0，两种 prompt 各跑一次
  - A 朴素问法：选 3 条 + 各 80 字摘要
  - B 加约束：JSON 输出 + 强制逐字引用 evidence + 强制合并重复

| 观察点 | 结果 |
|---|---|
| A 选的 3 条，我认可几条 | 【1】 |
| B 的 JSON 是否一次通过解析 | 【通过】 |
| 摘要中出现原文没有的信息 | 【有】 |
| 10 条里实际重复（同一事件） | 【无】 |

**结论一句话**：【模型能摘要但不会合并重复、也不会判断"对我重要"，这两点是项目要解决的核心。】

## 4. 目标（可度量）

| 指标 | 基线 | W12 目标 |
|---|---|---|
| 去重率（同事件重复条目占比） | 【填】 | < 5% |
| 有用率（我标"有用"的条目 / 总条目） | 【填】 | ≥ 70% |
| 忠实度（摘要中可在原文找到依据的句子占比） | 【填】 | ≥ 90% |
| 单期成本 | 【填】 | < ¥0.1 |
| 单期耗时（含抓取） | 【填】 | < 90 秒 |

## 5. 范围：三层演进

| 版本 | 能力 | 周次 | 验收 |
|---|---|---|---|
| v1 | 3 个源 → 规则去重 → 模型摘要 → markdown 输出 | W1–W2 | 每天手动跑一次，能读 |
| v2 | 向量去重 + 相关性打分 + 引用原文 + 偏好记忆 | W3–W6 | 选出来的条目明显更对味 |
| v3 | 多智能体（采集/筛选/写作/审校）+ 定时 + 质量自检 | W7–W9 | 无人值守跑一周不崩 |

## 6. 明确不做

1. 不做网页爬虫，只用 RSS 和公开 API（合规）
2. 不做推荐算法研究，embedding + 点击加权足够
3. 不做移动端，终端 + markdown；W9 之后可套一层网页
4. 不做多用户、不做账号体系
5. 不做"全网资讯"，固定 5 个源封顶

## 7. 为什么不是别的方案

- **直接用现成 newsletter**：排序是别人的，不按我的方向；且没有"我做出来的"可讲
- **每天手动问 ChatGPT**：这正是基线 A，重复劳动还在，且不可复现、无积累
- **只做 RAG 问答**：没有每日增量数据，无法持续练手

## 8. 数据与合规

- 信息源（全公开）：arXiv API、Hacker News API、GitHub Trending 页、2–3 个技术博客 RSS
- 存储：本地 SQLite（元数据）+ 向量库（W3 后加）
- 无个人隐私数据；发布前需注明来源与原文链接

## 9. 主要风险

| 风险 | 应对 |
|---|---|
| 源站改版/RSS 失效 | 抓取层与解析层分离，单源失败不阻塞整体 |
| 每天读不完导致放弃 | 简报硬性限制 5 条 + 300 字，宁可少 |
| 模型判断"重要"不准 | 用我的"有用/没用"做累积标注，W8 建评测集 |
| 成本失控 | 单期 token 上限 + 便宜模型兜底 |

## 10. 三个筛子

真实用户 5/5 · 可演示 5/5 · 可度量 4/5 = **14/15**

## 11. W12 成功标准

- [ ] 连续 7 天无人值守运行，失败自动告警
- [ ] 有用率 ≥ 70%（由累积 100 条标注算出）
- [ ] 3 分钟 demo 视频：从「空数据库」到「今天早上这份简报」
- [ ] 能说清三个技术取舍：为什么混合去重、为什么单 agent 起步、为什么这个评测指标
