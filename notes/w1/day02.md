# day02 · attention 到底在做什么

日期：2026-11-24 ｜ 阶段：W1 D2

## 一句话

每个词拿自己的 Q 去和所有人的 K 比相似度，softmax 成权重，再按权重把所有人的 V 加权求和。

## 四步流程

1. Q · K 点积 → 相似度分数
2. softmax → 权重（和为 1）
3. 权重 × V 求和 → 借来的信息
4. 加上自己 → 新表示

## 手算结果（3 词 2 维）

```
Q: 我[1,0] 爱[0,1] 你[1,0]
K: 我[1,1] 爱[0,1] 你[1,0]
V: 我[1,0] 爱[0,1] 你[0,1]

W 第 2 行（"爱"在看谁）= [0.42, 0.42, 0.16]
输出（"爱"的新表示）  = [0.42, 0.58]   ← 输入是 [0,1]，被改写了
```

## 三个反直觉点

1. **注意力权重是"相关度"，不是语法关系**。它不知道谁是主语，只知道"这两个位置该交换多少信息"。
2. **词的含义在每一层都被邻居改写**。输入 `[0,1]` → 输出 `[0.42,0.58]`，没有哪个词的表示只属于它自己。
3. **输出里没有"顺序"**。三行加权规则完全相同，模型分不出"我爱你"和"你爱我"——所以必须有位置编码。

## 实验教训

第一次跑出来三行输出完全相同，因为 V 里"爱"和"你"取了相同值，数据没有区分度。
**如果一个实验里所有结果都一样，先检查数据，别急着下结论。**
（把 Q 第一行改成 [1,1] 后，第 1 行权重立刻分化，输出也随之不同。）

## 权重是怎么分出来的（六个性质）

### 1. 零和预算：一行加起来必须等于 1

```
          你      是      谁     合计
你     0.422   0.155   0.422   1.000
```

给"谁"多分 0.1，就必须从"你"身上扣 0.1。注意力不是"给每个词打分"，
而是"把 100% 的预算分出去"。模型"忽略"某个词，不是判定它无关，是预算被更相关的挤掉了。

### 2. 只看相对差距，不看绝对值

实测：分数整体 +10，权重完全不变。

| 分数 | 权重 |
|---|---|
| [1, 0, 1] | [0.422, 0.155, 0.422] |
| [11, 10, 11] | [0.422, 0.155, 0.422] |

因为 softmax 先减掉最大值。"有多像"没有意义，"比别的候选更像多少"才有意义。

### 3. 差距大小决定"敢不敢押注"

| 分数 | 权重 | 效果 |
|---|---|---|
| [0.5, 0, 0.5] | [0.384, 0.233, 0.384] | 接近平均 |
| [1, 0, 1] | [0.422, 0.155, 0.422] | 基线 |
| [2, 0, 2] | [0.468, 0.063, 0.468] | 更集中 |
| [5, 0, 1] | [0.976, 0.007, 0.018] | 几乎全押第一个 |

**temperature 的物理含义**：不改变"谁最相关"，只改变"敢不敢押注"。

### 4. 差距由三个来源决定

1. Q·K 相似度 —— 本质
2. 向量长度 —— 长向量点积天然更大，所以要 ÷√d 缩放
3. 训练 —— W_q、W_k 是学出来的，"什么样的词该关注什么样的词"是梯度下降定的

### 5. 多头 = 多套预算

单个头只能分配一套权重，但一个词同时有语法、指代、语义多种关系。
所以 GPT 用多个头，每个头有自己的 W_q/W_k，各自独立分配，最后拼接。
**头的分工没有任何人设计**：有的学成"盯左边一个词"，有的学成"盯主语"，是训练自己长出来的。

### 6. 生成时不许看未来（causal mask）

把"未来位置"的分数设成 -∞，softmax 后权重为 0。矩阵变成下三角：
每个词只能把预算分给自己和左边。没有这条，模型就是作弊。

### 一句话

> 权重是**有限的预算**，按**相对差距**分配，差距由**相似度和温度**决定，
> 而"该和谁像"是**训练学出来的**。
