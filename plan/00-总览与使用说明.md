# AI Agent 学习计划 · 总览

> 为「会 Python、没做过 LLM 应用」的起点设计；每天 2 小时；12 周（84 天）完成从原理到可上线作品，并同步准备面试。
> 目标方向：Agent 应用原型 · 工作自动化落地 · 求职面试。

---

## 1. 这份计划解决什么问题

多数人的 AI 学习失败在三点：**只看不写**、**只写不懂**、**学完没有可展示的东西**。
本计划用三条硬约束对冲：

| 约束 | 具体做法 |
|---|---|
| 每天有产出 | 每天必须留下「代码 / 笔记 / 评测结果」中的至少一样，不允许纯输入 |
| 每天有复习 | 用 1-3-7-15-30 天间隔重复，打卡时先复习再学新内容 |
| 每两周有作品 | 6 个递进项目 + 1 个 capstone，全部可写进简历 |

---

## 2. 时间结构

- **总周期**：12 周 × 7 天 = 84 天。第 1–6 天学新内容，第 7 天只做复盘与补欠账。
- **每日 2 小时**（120 分钟固定切分）：

```
00–10  min  复习：到期卡片 + 昨日 3 句话回顾        ← 不跳过
10–70  min  理论：读/看/记，边看边写要点笔记
70–115 min  实践：写代码 / 做实验 / 跑评测
115–120 min 打卡：填表 + 写下"明天第一件事"
```

- **开始日期**：第 1 周周一 = **2026-11-23**。
  今天到 11/22 是「第 0 周准备期」，只做环境与选题，不占用正式进度。
- **弹性规则**：某天只完成 15 分钟也算打卡（复习 3 张卡 + 写 1 行）；
  断更不补课、只顺延；连续断 3 天，自动降级为「最小打卡模式」一周再恢复。

---

## 3. 五个阶段

| 阶段 | 周次 | 主题 | 里程碑产出 |
|---|---|---|---|
| 一、心智模型 | W1–W2 | LLM 如何生成、API 调用、上下文与提示词工程 | CLI 聊天机器人 + Prompt 模板库 |
| 二、知识供给 | W3–W4 | 嵌入、检索、RAG 与评测 | 带评测报告的 RAG 服务 |
| 三、行动能力 | W5–W6 | 工具调用、MCP、ReAct 与规划 | 手写 Agent 内核（不用框架） |
| 四、工程化 | W7–W9 | 编排框架、多智能体、评测、部署与安全 | 多智能体调研助手 + 线上 demo |
| 五、纵深与交付 | W10–W12 | 微调与对齐、capstone、面试冲刺 | 一个可展示的完整项目 + 面试题库过关 |

---

## 4. 三个目标如何同时满足

- **做 Agent 应用**：W5–W7 的项目就是 Agent 骨架；W11–W12 的 capstone 做成可演示产品。
- **工作自动化落地**：W2 的 D6、W5 的 D6 都直接选自己工作里真实的重复任务，学完即可用。
- **求职面试**：每周五道面试题（见 `03-面试题库与项目清单.md`），W12 集中模拟；
  6 个项目按 STAR 写成 6 个故事，面试时可直接讲。

## 6. 环境准备（第 0 周，5 天内完成）

1. **Python 3.11+**，用 `uv` 管理虚拟环境；`git` 建一个 `ai-agent-lab` 仓库，每天提交。
2. **一个 LLM API Key**：DeepSeek / 通义 / 智谱 / OpenAI 任选其一即可，先跑通再谈选型；
   预算按 ¥100–200 覆盖全程（大部分时间用便宜模型，评测时才用强模型）。
3. **编辑器与笔记**：VS Code + 一个 md 笔记目录（Obsidian 可选）；复习卡用 md 文件即可，不必上 Anki。
4. **账户**：GitHub（放项目）、一个向量库的本地方案（先用 Chroma，免注册）。
5. **选题**：想清楚 capstone 要解决谁的什么问题，写在 `notes/capstone-idea.md`。选题标准见 `03` 文件。

> 准备期不要读论文、不要买课。把 API 跑通，比什么都重要。

## 7. 参考资源（按需取用，不要通读）

- **原理直觉**：Karpathy《Let's build GPT》(视频)、bbycroft.net/llm（3D 可视化）、3Blue1Brown 神经网络系列
- **官方文档**：OpenAI Cookbook、Anthropic Prompt Engineering 指南、LangGraph 文档、MCP 官方规范
- **文章**：Lilian Weng《LLM Powered Autonomous Agents》、Anthropic《Building effective agents》
- **评测**：RAGAS 文档思路、Langfuse / LangSmith 的 tracing 概念
- **面试**：本仓库 `03` 文件 + 自己项目的复盘笔记（比背八股更有效）

原则：**每个资源只在被当天任务需要时打开**。收藏夹里躺着的教程不会让你变强。

## 8. 验收标准（12 周后你应该能）

- [ ] 不查资料，向别人讲清 token、attention、context window、temperature 各自影响什么
- [ ] 从零搭一个带引用、能拒答、有评测数据的 RAG 服务
- [ ] 手写 ReAct 循环，并能说清它与 workflow、与框架方案的取舍
- [ ] 用 LangGraph 或 Agents SDK 搭多智能体流程，并解释状态与中断怎么设计
- [ ] 为一个 agent 建评测集、接 tracing、算出成本与延迟
- [ ] 说清 prompt / RAG / 微调 三者的选择依据
- [ ] 有一个部署在线上、能演示、能讲 10 分钟的 capstone
- [ ] 40 道面试题能答出 35 道以上，两道系统设计能白板推演
