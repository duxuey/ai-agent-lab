# 资料清单：不用自己瞎找

> 三条原则：
> 1. **每天只有一个主资源**——当天任务需要什么就看什么，看完就关，不做"收藏式学习"。
> 2. **优先官方文档和一手论文**，二手教程只在卡住时用，且只用来解决那一个卡点。
> 3. **看完必须有产出**（代码/笔记/评测数据），否则这次阅读算没发生。

## 三、找资料的取舍规则

- **英文优先**：这个领域的中文资料平均滞后 3–6 个月，且二手转述多。看英文慢，但只慢前两周。
- **看版本日期**：2024 年以前的 agent 教程直接跳过，接口和最佳实践全变了。
- **一个主题最多开 3 个页面**，超了就关掉，先动手写。
- **卡住超过 20 分钟**：先跑最小可运行示例，再回来看原理；或者直接问我。
- **不追新模型新闻**：12 周内模型会换两三代，你要学的是接口和设计模式，不是某个模型的特性。

## 四、你不需要买的

- 系统课/训练营：本计划的日程已经是课程表，缺的只是执行。
- 论文精读课：4 篇论文读摘要和方法图足够应付面试。
- "AI Agent 全栈"类电子书：等 W12 之后再买，那时你才知道自己缺什么。

## 五、什么时候该问我

- 某天的资料找不到、或找到的互相矛盾；
- 概念看懂了但不知道代码怎么写；
- 想让我把某个主题讲成"人话版"（比如"用仓库拣货比喻讲 RRF"）；
- 想让我按当天主题直接给一个最小可运行示例。
